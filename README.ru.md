# codex-task-authoring

[English](README.md) | Русский

[![skills.sh](https://skills.sh/b/d1ms1m/codex-task-authoring-skill)](https://skills.sh/d1ms1m/codex-task-authoring-skill)

`codex-task-authoring` — публичный автономный skill для Codex, который создаёт, редактирует и ревьюит готовые к реализации инженерные задачи. Он выбирает frontend-, backend- или fullstack-профиль, загружает только релевантные инструкции и при необходимости формирует отдельный API delta для отсутствующих или изменяемых backend-возможностей.

Skill ставит решения на первое место: основывает требования на фактах репозитория, сохраняет явные решения и неизменяемое поведение, отличает блокеры от безопасных допущений и формулирует измеримые критерии приёмки. Он не реализует описанную функциональность и не превращает задачу в execution plan без явного запроса.

## Использование

Явный вызов:

```text
$codex-task-authoring Создай готовую к реализации frontend-задачу на основании этих требований и фактов репозитория.
```

```text
$codex-task-authoring Проверь эту backend-задачу на пробелы в контрактах и непроверяемые критерии приёмки. Не переписывай её.
```

Описание skill также поддерживает автоматическое срабатывание, когда запрос явно требует инженерную задачу, feature specification, ревью или редакцию задачи либо API delta. Обычные запросы на реализацию, отладку, редактирование Markdown, product discovery и подробное планирование исключены.

Создаваемые артефакты используют язык запроса или проекта. Технические идентификаторы сохраняются, если перевод сделал бы их неоднозначными.

## Профили и progressive disclosure

- **frontend:** поведение UI, маршрутизация и URL-state, клиентское состояние, композиция, доступность и frontend-проверки;
- **backend:** контракты, авторизация, доменные переходы, идемпотентность, конкуренция, транзакции, rollout и операционные проверки;
- **fullstack:** оба профиля, а также владение изменениями, синхронизация API-границы, независимо развёртываемый rollout и сквозные критерии приёмки;
- **API delta:** только отсутствующая или изменяемая backend-возможность без дублирования неизменившейся API-документации.

`SKILL.md` содержит общий workflow и маршрутизацию. Условные подробности находятся в отдельных reference-файлах, поэтому нерелевантные checklist-ы не занимают контекст.

## Установка

### Установка через skills.sh из удалённого репозитория

В терминале выполните:

```powershell
npx skills add d1ms1m/codex-task-authoring-skill --skill codex-task-authoring --global --agent codex
```

Клонировать репозиторий или открывать skills.sh не нужно. [Skills CLI](https://github.com/antfu/skills-cli) скачает skill прямо из этого GitHub-репозитория. `--global` делает skill доступным во всех проектах Codex; уберите флаг, чтобы установить его только в текущий проект. `--agent codex` устанавливает skill только для Codex.

Для установки на уровне проекта уберите `--global`:

```powershell
npx skills add d1ms1m/codex-task-authoring-skill --skill codex-task-authoring --agent codex
```

### Установка через skills.sh из локальной копии

Выполняйте эти команды из корня локальной копии:

```powershell
npx skills add . --skill codex-task-authoring --global --agent codex
```

`--global` делает skill доступным во всех проектах Codex; уберите флаг, чтобы установить его только в текущий проект. `--agent codex` устанавливает skill только для Codex.

```powershell
npx skills add . --skill codex-task-authoring --agent codex
```

Skills CLI не является продуктом OpenAI. Перед глобальной установкой проверьте его исходный код и diff выпуска. Для любого варианта установки через Skills CLI используйте следующие команды, чтобы проверить наличие обновлений и установить их:

```powershell
npx skills check
npx skills update
```

### Установка в Codex из GitHub

В сообщении Codex запустите:

```text
$skill-installer Install the skill from https://github.com/d1ms1m/codex-task-authoring-skill/tree/master/skills/codex-task-authoring
```

Чтобы зафиксировать уже опубликованную версию вместо `master`, используйте URL её тега (например, `v0.1.0`):

```text
$skill-installer Install the skill from https://github.com/d1ms1m/codex-task-authoring-skill/tree/v0.1.0/skills/codex-task-authoring
```

Skill станет доступен в следующем сообщении. Если он не появился, перезапустите Codex. Подробнее — в официальной документации OpenAI [Codex skills](https://developers.openai.com/codex/skills).

Codex поддерживает автономные skills. OpenAI рекомендует plugins для распространения переиспользуемых skills за пределами одного репозитория или вместе с другими skills и коннекторами; этот репозиторий пока распространяет автономный skill.

## Структура репозитория

- `skills/codex-task-authoring/` — устанавливаемый skill, метаданные, references и шаблоны результата;
- `tests/fixtures/` — входные данные для forward-тестов профилей, неоднозначности и review;
- `tests/rubrics/task-quality.md` — наблюдаемые поведенческие инварианты;
- `tests/forward-test-report.md` — результаты слепых forward-тестов и исторический trigger-аудит;
- `docs/releases/v0.1.1.md` — примечания к релизу и результаты проверок;
- `tests/test_repository_contract.py` — детерминированные проверки упаковки и гигиены;
- `docs/design.md` — исторический дизайн первоначальной версии 0.1.0.

## Проверка

Запустите детерминированные проверки репозитория:

```powershell
python -m pip install -r requirements-dev.txt
python -m unittest discover -s tests -p "test_*.py" -v
```

Запустите актуальный `quick_validate.py` из официального OpenAI `skill-creator` для `skills/codex-task-authoring`. CI загружает закреплённую и проверенную ревизию официального Skill Creator и выполняет оба уровня валидации. Качество поведения по-прежнему требует forward-тестирования версионированных fixtures: статические проверки не заменяют оценку результата модели.

## Ограничения

- Skill не может самостоятельно разрешить влияющий на контракт конфликт, если ответ отсутствует в авторитетных источниках: он задаёт один сфокусированный вопрос и останавливается.
- Он не гарантирует, что сторонние installers, настройки моделей по умолчанию, цены, доступность продуктов или поведение API остаются актуальными.
- По умолчанию skill работает с документацией и не изменяет продуктовый код или внешние системы.
- Версия `0.1.1` использует forward-тесты по rubric вместо хрупкого сравнения полного текста ответа. Неизменяемые соглашения проекта допускается указывать по ссылке без выдумывания всех частных случаев; существенные конфликты контрактов и прав по-прежнему требуют точного вопроса.

## Разработка и проверка

При изменении skill сохраняйте entrypoint компактным, а условные инструкции размещайте в одном легко обнаруживаемом reference-файле. Для каждого изменения поведения добавляйте или обновляйте fixture. Перед предложением изменения запускайте репозиторные тесты, валидацию Skill Creator и затронутые forward-сценарии. Не добавляйте общее правило из-за единичного сбоя, пока fixture не докажет обобщаемый пробел.
